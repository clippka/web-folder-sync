      How connecting works
      • Each browser profile connects its own folder. The connection and sync records live in this browser's site data: if you clear them, this browser forgets the folder and joins again as a new device. Joining only ever adds files; nothing is deleted because a record is missing.
      • The app can detect overlapping folders only inside one browser profile. Do not connect the same folder (or a folder and its parent) from two different browser profiles or computers at once.
      • Syncing runs only while this page is open and you started it. A suspended or closed tab stops the run; start it again to continue. If another program edits a file at the very moment it is replaced, that edit can be lost: close editors on files you expect to change remotely.

      Only the current version of each file is kept: no history, trash or per-file restore. Content is stored on the server unencrypted by the app, so the server operator can read it.
